# Contributing

Thanks for your interest in Food Diary. It is a deliberately small, personal tool: before proposing a new feature, open an issue to discuss whether it fits.

- [Development](docs/development.md) — run the app from source, work on the frontend with a mocked backend, and manage database migrations.
- [Releasing](docs/releasing.md) — how a new version is published to Docker Hub and GitHub.

## Questions and problems

For bugs, suggestions and questions, [open a GitHub issue](https://github.com/pkirilin/food-diary/issues).
